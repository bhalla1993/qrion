Why it exists

Qrion helps developers write safer prompts for AI coding tools.

AI coding tools are fast, but prompts can still be vague, broad, or too expensive for a limited plan. Qrion sits in front of those tools and gives you a quick, explainable read on whether a query is likely to stay small or turn into a repo-wide change.

It is not trying to predict an agent exactly. It is trying to help you write a better prompt with a clearer sense of scope and cost.

Shows the next best action and a copyable refined prompt so the developer can move from analysis straight to a better query.

How it works

Static heuristics, clear reasons, no remote model calls.

  1. Read the prompt and extract features such as vague, multi-step, and repo-wide language.
  2. Index the workspace and rank relevant files using lightweight heuristics.
  3. Estimate token pressure and compute a risk score with explainable reasons.
  4. Return model advice, rewrite tips, split suggestions, a next action, and a copyable refined prompt.

Built to stay honest

Qrion is intentionally approximate.

It does not simulate an agent, does not call a remote model, and does not pretend to know the exact files or tokens a coding assistant will use.

Who it is for

Helpful when prompts need to stay focused and affordable.

Qrion is useful for developers who use AI coding tools daily, especially when plan limits, token budgets, or large refactors make prompt quality matter more.

Use it locally

CLI and VS Code workflows stay simple on purpose.

The report now leads with the verdict, intent, next action, refined prompt, and top files so the default output stays useful in the moment, not just informative. Use `--verbose` when you want the full risk and token breakdown, `--color` to force colors, and `--no-color` to disable them. General chat prompts are now called out of scope instead of being treated like code-change requests.

CLI

Fast check 
npx qra analyze "Refactor auth module to use JWT instead of sessions."
npx qra analyze --json "Refactor the auth and billing flows."
npx qra analyze --file prompt.txt

Limitations

Honest by design, not pretending to be an oracle.

  • Heuristics are approximate by design.
  • Qrion does not simulate any specific agent.
  • It does not guarantee exact file or token usage.
  • It is a planning aid, not an execution engine.

Technical shape

Small monorepo, clear package boundaries.

  • @qra/core for deterministic analysis.
  • @qra/cli for terminal use.
  • @qra/vscode for editor workflows.
  • TypeScript, Node.js, and local-only processing.
