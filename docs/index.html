Qrion helps developers judge an AI prompt before they send it.

Qrion is a deterministic pre-flight analyzer for AI coding workflows. It estimates prompt risk, scope, token pressure, likely files, and suggested prompt rewrites without calling any AI model.

Why Qrion exists

AI coding tools are fast, but prompts can still be vague, broad, or too expensive for a limited plan. Qrion is meant to sit in front of those tools and give you a quick, explainable read on whether a query is likely to stay small or turn into a repo-wide change.

It is not trying to predict an agent exactly. It is trying to help you write a better prompt.

What is built now

Risk and scope

Scores prompts from Low to High based on vague wording, repo-wide language, multi-step instructions, sensitive areas, and context pressure.

Likely files

Indexes the workspace and ranks files using filename, folder, import, and symbol hints so the output includes likely areas of change.

Token estimate

Produces a low/high token range for the query and relevant files so you can spot context pressure early.

Rewrite and split tips

Gives deterministic advice for narrowing broad prompts or breaking them into safer steps.

How it works

  1. Read the prompt and extract features such as vague, multi-step, and repo-wide language.
  2. Index the workspace and rank relevant files using lightweight heuristics.
  3. Estimate token pressure and compute a risk score with explainable reasons.
  4. Return model advice, rewrite tips, split suggestions, and a concise summary.

Built to stay honest

Qrion is intentionally approximate. It does not simulate an agent, does not call a remote model, and does not pretend to know the exact files or tokens a coding assistant will use.

Who it is for

Qrion is useful for developers who use AI coding tools daily, especially when plan limits, token budgets, or large refactors make prompt quality matter more.

Use it locally

CLI

npx qra analyze "Refactor auth module to use JWT instead of sessions."
npx qra analyze --json "Refactor the auth and billing flows."
npx qra analyze --file prompt.txt

VS Code

Run the commands for selected text, clipboard text, or a manual query and review the report in the Qrion sidebar panel.

The extension uses the current workspace as its repo root.

Limitations

  • Heuristics are approximate by design.
  • Qrion does not simulate any specific agent.
  • It does not guarantee exact file or token usage.
  • It is a planning aid, not an execution engine.

Technical shape

  • @qra/core for deterministic analysis.
  • @qra/cli for terminal use.
  • @qra/vscode for editor workflows.
  • TypeScript, Node.js, and local-only processing.
